Project Case Study · 03
MapToMatrix

A generalized Google Earth Engine + Colab workflow that turns any AOI shapefile into a labeled raster grid, then a coordinate-annotated matrix text file, ready to feed straight into a script instead of a GIS.

RoleIndependent Tool
StackGoogle Earth Engine (JS) · Python · Colab
OutputLabeled AOI Matrix (.txt)

Overview

Most AOI (Area of Interest) workflows stop at a raster or vector layer sitting inside a GIS. MapToMatrix pushes one step further: it converts an AOI shapefile into a plain-text, human-and-script-readable matrix, where every cell is classified 0 (outside the AOI), 1 (inside), or 2 (boundary), and the matrix itself is annotated with latitude labels down the right edge and longitude labels along the bottom.

The pipeline splits cleanly across two free platforms. A Google Earth Engine script takes an uploaded shapefile asset and exports a classified raster grid to Google Drive at a chosen pixel resolution (3000 m / ~3 km by default). A Google Colab script then reads that GeoTIFF and writes it out as a coordinate-labeled .txt matrix, with adjustable label density so wide rasters don't end up with unreadably dense coordinate ticks.

How It Works

  1. Upload an AOI shapefile to Google Earth Engine Assets, then point the GEE script at that asset path.
  2. Run the GEE script with the chosen pixel size and export folder; it classifies every pixel (outside / inside / boundary) and exports the result as a GeoTIFF to Google Drive.
  3. Run the Colab script against that GeoTIFF; it writes a labeled .txt matrix, with latitude values appended on the right and longitude values along the bottom, ready to load directly into any downstream script without a GIS in the loop.

Why It Matters

A lot of downstream modelling work (custom raster processing, cellular-automata style simulations, quick spatial masks for non-GIS scripts) just needs a classified grid with known coordinates, not a full raster stack. MapToMatrix removes the GIS dependency from that last step, so an AOI defined once in a shapefile can be reused directly inside plain Python, MATLAB, or any language that can read a text matrix.
